Política de Privacidade

Controle Pro — Última atualização: outubro de 2026

1. Informações que coletamos

O app Controle Pro coleta apenas os dados necessários para o funcionamento dos serviços de gestão (vendas, produtos, estoque, financeiro e usuários), informados pelo próprio usuário durante o uso do app.

2. Anúncios e publicidade (AdMob)

Utilizamos o Google AdMob para exibir anúncios no app (versão gratuita). Para isso, o Google pode coletar:

  • Identificador de publicidade (Advertising ID / IDFA) — usado para personalizar anúncios.
  • Dados do dispositivo (modelo, sistema operacional, versão do app).
  • Dados de uso do app (interações com os anúncios).

Esses dados são tratados pelo Google conforme a Política de Privacidade do Google. Você pode optar por não personalizar anúncios nas configurações do seu dispositivo.

Importante: O app não vende seus dados pessoais a terceiros. O acesso aos dados de gestão (vendas, produtos etc.) é protegido por autenticação e controle de acesso no servidor.

3. Como usamos suas informações

  • Para operar os serviços de gestão contratados (vendas, estoque, financeiro).
  • Para exibir anúncios na versão gratuita (quando habilitado).
  • Para autenticação e segurança da conta.

4. Compartilhamento com terceiros

Compartilhamos dados apenas com:

  • Google (AdMob) — para exibição de anúncios.
  • Supabase — infraestrutura de banco de dados e autenticação (dados em repouso criptografados).

5. Seus direitos (LGPD)

Nos termos da Lei Geral de Proteção de Dados (LGPD), você tem o direito de:

  • Confirmar a existência de tratamento dos seus dados.
  • Acessar, corrigir ou solicitar a exclusão dos seus dados.
  • Revogar o consentimento para anúncios personalizados.

Para exercer esses direitos, entre em contato conosco (veja abaixo).
