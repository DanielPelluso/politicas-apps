# Políticas — Apps Pelluso

Site estático com as políticas dos apps (GitHub Pages).

## Ativação

1. Crie um repo neste GitHub com este conteúdo (ex.: `politicas-apps`).
2. Vá em **Settings → Pages → Deploy from a branch → `main` / raiz** → **Save**.
3. O site ficará em: `https://<usuario>.github.io/politicas-apps/`

## Páginas

- `index.html` — Política de Privacidade (Controle Pro)
- `termos.html` — Termos de Uso (Controle Pro)

Para adicionar outro app depois: crie `app-nome.html` e `app-nome-termos.html` (ou subpasta), e adicione links em `index.html`.

## URLs para configurar nas lojas

Copie a URL final do Pages e cole em:

- **AdMob console** → Apps → Privacy & messaging
- **Play Store** → Listing → Política de Privacidade
- **App Store Connect** → App Privacy
